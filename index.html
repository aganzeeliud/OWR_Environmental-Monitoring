Scientific Standards & Methodology

1. Earth Observation Integration

The platform integrates multi-spectral satellite streams from Landsat-8/9 and Sentinel-2, combined with thermal alerts from MODIS and VIIRS. Forest loss is quantified using the Hansen Global Forest Change methodology, ensuring global comparability.

Primary Forest Mapping

30m resolution pixel-based change detection covering all of Ituri Province.

Carbon Calibration

GEDI Space-LiDAR biomass metrics used to calibrate carbon emission estimates.

2. Analysis Standards

All area-based results are computed in Hectares (ha) using sinusoidal projections to minimize distortion in equatorial regions. Accuracy assessment is performed using stratified random sampling with high-resolution Planet NICFI imagery.
