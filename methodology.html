The Methodology

Standardized protocols for forest loss quantification, multi-sensor integration, and temporal change detection in the Congo Basin.

1. Multi-Sensor Data Fusion

The OWR Platform integrates four primary data streams to ensure a high-fidelity monitoring pipeline:

Hansen GFC (UMD)

Decadal forest loss quantification at 30m resolution. Primary temporal baseline.

MODIS & VIIRS (NASA)

Thermal anomaly detection and burned area mapping via NASA FIRMS.

Sentinel-2 (ESA)

10m resolution optical validation for industrial encroachment hotspots.

GEDI (NASA)

Laser altimetry for above-ground biomass and carbon flux modeling.

3. Analysis Algorithms

We employ Parametric Spectral Change Detection to identify anomalies indicative of forest degradation.

# OWR CHANGE DETECTION KERNEL
def detect_deforestation(pixel, baseline, threshold=0.15):
    NDVI = (pixel.NIR - pixel.RED) / (pixel.NIR + pixel.RED)
    if NDVI < (baseline.NDVI - threshold):
        area_ha = (pixel.resolution ** 2) / 10000
        return True, area_ha
    return False, 0
